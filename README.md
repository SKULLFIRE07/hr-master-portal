# Master Portal

Single-page employee portal for PBP: Payroll, IT Help Desk, Mediclaim, Sales Support,
HR Helpdesk, Employee Benefits and Travel & EC Grievances.

- `index.html` is the whole app (HTML, CSS and JS in one file, no build step).
- `pbp-logo.png` is the header logo.

Open `index.html` in a browser to run it locally.

The page lists staff names, phone numbers and email addresses.
